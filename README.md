Calibrated Monte Carlo forecaster for GTA VI's launch-day Twitch viewers: it reads a case's hour-1 print plus the past big-launch curves in the case file, regresses each hour's log viewer ratio on launch scale, and simulates 40,000 antithetic trajectories to read off five quantiles per hour (practice pinball loss 0.152 vs house baseline 0.387).

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
